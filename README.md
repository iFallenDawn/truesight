# True Sight
A list of all of Jordan (iFallenDawn) written guides for MapleStory bosses migrated from Notion because I wanted some form of version control using git without writing a changelog. Decided on using MkDocs because I hate doing anything front end related.

These guides will include everything I personally learned and gathered for the boss during my progression.

Includes guides on:

- Kaling
- Malefic Star
- Kalos (WIP)

## Commands

* `mkdocs new [dir-name]` - Create a new project.
* `mkdocs serve` - Start the live-reloading docs server.
* `mkdocs build` - Build the documentation site.
* `mkdocs -h` - Print help message and exit.
* `mkdocs gh-deploy` - Deploy to gh-pages
